# Créditos

## Ícones

Ícones de [game-icons.net](https://game-icons.net), sob a licença
[Creative Commons BY 3.0](https://creativecommons.org/licenses/by/3.0/)
(Zeromancer: CC0). Icons made by Lorc, Delapouite, Felbrigg, Willdabeast,
Skoll, Faithtoken, Lucas, DarkZaitzev e Zeromancer.

O código que gera `src/ui/gameIcons.ts` apenas extrai o traçado dos SVGs originais,
sem alterar o desenho.

## Arte

Silhuetas de personagens e monstros, cenários e interface: feitas para este projeto (`src/ui/art.ts`, `src/style.css`).

## Obra original

Sword Art Online pertence a Reki Kawahara / Kadokawa / Aniplex. Este é um projeto de fã, sem fins comerciais.
